# 优化大纲（WANGJIA 印尼销售平台）

更新：2026-11-08。状态标记：✅ 已完成并验证 · 🔧 代码已完成、需真实环境验证 · ⏳ 待做 · 🔑 需要 李总/公司提供输入。

## 不做清单（避免臃肿）

- Meilisearch / Elasticsearch（SKU 少）
- 自建 CMS（博客用代码管理）
- 单点登录 / Keycloak
- 自研支付或钱包
- 社区、论坛、积分商城
